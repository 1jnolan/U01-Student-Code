Helpful Website Editing Tips

  • To change the background colour of the entire website, edit the body rule in the CSS file and change the background-color property.
  • To change the colour of a section, edit the section rule and change the background-color value.
  • To change the colour of the navigation menu, edit the nav rule.
  • To change heading colours, edit the h1 and h2 rules.
  • To change the font style of all text, modify the font-family property in the body rule.
  • Popular font choices include: Arial, Verdana, Georgia, Times New Roman and Trebuchet MS.
  • To change the size of headings, edit the font-size property within the h1 or h2 rules.
  • To centre text on the page, use: text-align: center;
